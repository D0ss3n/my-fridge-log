# Fridge Friend

hemsida som håller reda på vad man har kvar i kylskåpet. Man skannar in sina varor och sedan scannar när de tagit slut så att den ständigt uppdateras. Så man kan hålla koll när man är i butiken tex och undrar om man har de hemma eller inte? Inte scanna, utan lägger in vara via text
